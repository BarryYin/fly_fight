# 游戏音频文件夹

这个文件夹包含游戏所需的所有音频文件。请确保以下文件存在：

## 必需音频文件

1. `shoot.mp3` - 射击音效
2. `explosion.mp3` - 爆炸音效
3. `engine_loop.mp3` - 引擎循环音效
4. `hit.mp3` - 击中音效
5. `menu_click.mp3` - 菜单点击音效（可选）
6. `powerup.mp3` - 获得道具音效（可选）
7. `battle_music.mp3` - 战斗背景音乐（可选）
8. `menu_music.mp3` - 菜单背景音乐（可选）

## 创建测试音频

如果你暂时没有音频文件，可以使用在线音频生成工具创建示例文件，如：
- [Bfxr](https://www.bfxr.net/) - 适合创建像素风格的音效
- [ChipTone](https://sfbgames.itch.io/chiptone) - 生成简单的游戏音效

## 音频格式注意事项

- 使用MP3格式确保较好的浏览器兼容性
- 保持文件尺寸较小（每个文件建议小于1MB）
- 确保音量适中，避免音效过响

## 音频错误处理

游戏代码已经包含了音频错误处理，如果音频文件缺失，游戏仍然可以正常运行。
