# 无人机战斗模拟游戏

一个基于Three.js开发的3D无人机战斗模拟游戏，支持单人模式和多人联机模式。

## 游戏特性

- 3D无人机飞行控制系统
- 第一人称和第三人称视角切换
- 自动生成的敌方AI无人机
- 实时多人联机git add README.md
对战
- 可破坏的环境元素
- 雷达和小地图系统

## 操作说明

- **WASD**: 移动
- **空格键**: 发射武器
- **鼠标**: 控制视角
- **V键**: 切换视角模式
- **M键**: 开关小地图
- **P键**: 显示玩家列表

## 技术栈

- Three.js - 3D图形渲染
- WebSockets - 实时多人联机
- Node.js - 服务器后端

## 如何游玩

### 单人模式
直接打开index.html或启动服务器访问

### 多人模式
1. 启动多人游戏服务器: `node server_multiplayer.js`
2. 在浏览器中访问: `http://localhost:3000`
3. 分享你的IP地址给朋友，让他们加入游戏
